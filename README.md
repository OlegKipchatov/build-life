# BuildLife

Приложение для задач, глобальных целей и развития персонажа.

## Возможности

- Задачи с расписанием, выполнением и архивом.
- Вехи с прогрессом по связанным задачам.
- RPG-профиль: уровень, опыт, характеристики и навыки.
- Настройки персонажа, русский и английский языки, светлая, тёмная и системная темы.

## Локальный запуск

Приложение работает на HTML, CSS и JavaScript без сборки и зависимостей.

```sh
python3 -m http.server 8000 --directory docs
```

Откройте http://localhost:8000.

## GitHub Pages

В Settings → Pages выберите Deploy from a branch, ветку main и каталог /docs. Изменения в main публикуются автоматически стандартным процессом GitHub Pages. Все пути к ресурсам относительные и поддерживают адрес проекта /build-life/.

## Данные

Данные хранятся в localStorage браузера под ключом buildlife-v1. Серверного хранилища и синхронизации нет. Данные предыдущего домена Sites не переносятся автоматически на GitHub Pages: браузер изолирует хранилища разных доменов. Пользовательские данные и секреты в репозиторий не включены.
